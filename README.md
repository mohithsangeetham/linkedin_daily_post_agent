# LinkedIn Daily Post Generator using Claude

This project is a Google Colab-based LinkedIn content generator that helps create daily LinkedIn posts for topics such as Data Science, QA Automation, SDET, Python, API Testing, Job Search, and Career Growth.

The notebook uses Claude for generating LinkedIn post content, captions, hashtags, and topic ideas. It also creates professional PNG visuals using Python, so no external image generation tools such as Gemini, Imagen, OpenAI image generation, or Pexels are required.

## Features

- Generate daily LinkedIn post ideas
- Create professional LinkedIn captions
- Generate hashtags automatically
- Create PNG visuals using Python
- No image-generation API required
- No Gemini, Imagen, OpenAI image, or Pexels dependency
- Suitable for Data Science, SDET, QA Automation, and career-focused LinkedIn posting

## Visual Types Created

The notebook can create different types of professional PNG visuals, including:

- Data Science Dashboard
- QA Automation Workflow
- API Testing Report
- Python Code Snippet
- Job Search Tracker
- Learning Roadmap
- Project Showcase
- Achievement Tracker

## How It Works

1. The user selects or generates a LinkedIn topic.
2. Claude generates the LinkedIn post caption and hashtags.
3. Python creates a professional PNG visual based on the selected topic.
4. The final output includes:
   - LinkedIn post caption
   - Hashtags
   - PNG image
   - Saved output files
